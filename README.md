# For Anne 💖
```
npm install
npm run dev     # http://localhost:3000
```
Edit the lines and signature at the top of `app/page.js`.
Deploy free: push to GitHub, import on vercel.com.

Want your own photo as the background? Drop it in `public/` (e.g. `public/us.jpg`) and set `PHOTO = "/us.jpg"` at the top of `app/page.js`.


## Getting her answer (no accounts or subscriptions)
When she says yes, her screen shows "Text Oscar 💌" and "WhatsApp Oscar 💬" buttons. They open a ready-typed "I said YES 💖" message to you.
Your number stays private: set it only as the `OSCAR_PHONE` environment variable on your host (e.g. `OSCAR_PHONE=+233...`), or in `.env.local` when testing. It never appears in the page's code.
The 🎵 button mutes the music-box tune.
